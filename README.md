# Customer Segmentation Analysis using Power BI

## Overview

This project presents a comprehensive analysis of bank customer segmentation using Power BI. It leverages a dataset of customer information to identify patterns, behaviors, and segments based on demographics, financial data, and other attributes. The analysis aims to provide insights into customer profiles, aiding in targeted marketing, risk assessment, and personalized banking services.

## Features

- **Interactive Dashboards**: Explore customer data through dynamic visualizations including charts, graphs, and maps.
- **Segmentation Insights**:
  - Demographic breakdowns by gender, age, region, and job classification.
  - Financial analysis including balance distributions and averages.
  - Temporal trends in customer acquisition and balance growth.
- **Key Visualizations**:
  - Count of customers by gender and job classification.
  - Age distribution and balance summaries.
  - Regional comparisons of average balances.
  - Monthly trends in balance sums and customer counts.
  - Gender-based balance analysis across regions and job types.

## Dataset

The analysis is based on the `Bank Customer Dataset.csv`, which includes the following fields:
- **Customer ID**: Unique identifier for each customer.
- **Name**: First name of the customer.
- **Surname**: Last name of the customer.
- **Gender**: Male or Female.
- **Age**: Age of the customer.
- **Region**: Geographic region (England, Scotland, Wales, Northern Ireland).
- **Job Classification**: White Collar, Blue Collar, or Other.
- **Date Joined**: Date the customer joined the bank.
- **Balance**: Current account balance.

The dataset contains over 4,000 customer records, providing a robust sample for segmentation.

## Requirements

To view and interact with the Power BI report:
- **Power BI Desktop**: Download and install from [Microsoft Power BI](https://powerbi.microsoft.com/desktop/).
- No additional software is required for viewing the PDF report or dataset.

## Usage

1. **Open the Power BI File**:
   - Download `Customer Segmentation Analysis using Power BI.pbix`.
   - Open it in Power BI Desktop to explore interactive dashboards.

2. **View the PDF Report**:
   - Open `Customer Segmentation Analysis using Power BI.pdf` for a static overview of the visualizations.

3. **Analyze the Dataset**:
   - Use `Bank Customer Dataset.csv` in tools like Excel, Python (pandas), or R for further analysis.

## Insights

- **Demographics**: The dataset shows a balanced gender distribution with slight variations across job classifications. White Collar jobs dominate in higher balance categories.
- **Regional Trends**: England has the highest customer count, while Northern Ireland shows the highest average balance.
- **Financial Behavior**: Balances vary significantly by age, with peaks in middle-aged groups. Monthly trends indicate steady growth in total balances.
- **Segmentation Opportunities**: Customers can be segmented into high-value (high balance, White Collar), potential growth (younger age groups), and regional focus areas.
